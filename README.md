Книга рецептов (Recipe Book)
Учебное приложение для хранения ингредиентов и рецептов. Реализовано на Python, SQLAlchemy ORM и SQLite. Поддерживает работу через командную строку (CLI) и графический интерфейс (GUI) на базе Tkinter.

Проблема и цель
Рецепты и списки ингредиентов часто хранятся разрозненно. Из-за этого сложно найти блюдо по имеющимся продуктам, сравнить время приготовления и сохранить последовательность операций для сложных блюд. Приложение собирает каталог в одном месте и поддерживает поиск по названию, категории, способу приготовления, времени и ингредиентам.

Бизнес-требования
ID | Требование | Критерий приёмки
BR-01 | Каталог хранит ингредиенты с единицами измерения и категориями | Ингредиент можно создать и просмотреть в CLI/GUI
BR-02 | Рецепт содержит название, категорию, время, способ и порции | Рецепт сохраняется со списком ингредиентов и шагами
BR-03 | Сложный рецепт состоит из упорядоченных операций | Шаги возвращаются в заданном порядке (position)
BR-04 | Пользователь ищет рецепты по названию и фильтрам | Поиск поддерживает текст, категорию, способ и верхний предел времени
BR-05 | Пользователь ищет рецепты, содержащие указанные ингредиенты | Можно передать один или несколько ингредиентов (режим "все" или "любой")
BR-06 | Данные переживают перезапуск приложения | SQLAlchemy сохраняет данные в SQLite-файл

Область первой версии
Включены каталог ингредиентов, создание/чтение рецептов, фильтрация, консольный интерфейс и графический интерфейс. Авторизация, изображения, редактирование/удаление и планирование меню не входят в первую версию.

Архитектура
Слои: Интерфейсы (CLI / Tkinter GUI) → Схемы ввода/вывода (dataclasses) → Сервисы предметной области → SQLAlchemy ORM и SQLite. Интерфейсы не содержат SQL-запросов напрямую; бизнес-операции сосредоточены в сервисах (CatalogService, RecipeService).

Запуск
Требуется Python 3.12 или новее.

python -m venv .venv
# Windows PowerShell:
.venv\Scripts\Activate.ps1
# macOS/Linux: 
source .venv/bin/activate

pip install -e .
# или установка зависимостей напрямую:
pip install SQLAlchemy

Заполнение базы демонстрационными данными:
python -m recipe_book seed

Запуск графического интерфейса:
python -m recipe_book gui

Запуск консольных команд:
python -m recipe_book --help

База recipe_book.sqlite3 создается в текущей директории при первом запуске. При первом запуске GUI, если база пуста, приложение предложит загрузить демо-данные.

CLI-команды
python -m recipe_book init — создать таблицы базы данных.
python -m recipe_book seed [--reset] — заполнить демо-данными (сброс схемы при --reset).
python -m recipe_book categories — показать категории и операции.
python -m recipe_book category-add — добавить категорию.
python -m recipe_book ingredients — список ингредиентов.
python -m recipe_book ingredient-add — добавить ингредиент.
python -m recipe_book operations — список операций.
python -m recipe_book recipes — список рецептов.
python -m recipe_book recipe-show <id> — получить рецепт.
python -m recipe_book search — поиск по параметрам: --query, --category, --max-time, --method, --ingredient, --any-ingredients.

Пример поиска из консоли:
python -m recipe_book search --ingredient "Куриное филе" --ingredient "Сливки"
python -m recipe_book search --category "Супы" --max-time 45
