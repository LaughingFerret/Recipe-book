# Recipe Book

Приложение для ведения каталога рецептов. Реализовано на Python с использованием SQLAlchemy ORM и SQLite. Поддерживает работу через интерфейс командной строки (CLI) и графический интерфейс (GUI) на базе Tkinter.

## Назначение

Приложение предназначено для централизованного хранения информации об ингредиентах, кулинарных операциях и рецептах. Позволяет структурировать процесс приготовления сложных блюд, разбивая его на отдельные шаги с указанием времени и используемых продуктов.

## Функциональные возможности

- **Справочники**: ведение категорий для ингредиентов и рецептов, справочник кулинарных операций (варка, жарка, нарезка и т.д.).
- **Рецепты**: создание карточек рецептов с указанием порций, общего времени и пошагового описания процесса. Ингредиенты можно привязывать к конкретным шагам.
- **Поиск**: фильтрация рецептов по текстовому запросу (название, описание), категории, максимальному времени приготовления, конкретной операции или входящим ингредиентам (с поддержкой логики «И» / «ИЛИ»).
- **Интерфейсы**: полноценная работа как из терминала, так и через визуальные формы.

## Технологический стек

- **Язык**: Python 3.12+
- **База данных**: SQLite
- **ORM**: SQLAlchemy 2.0 (с использованием типизации `Mapped`)
- **GUI**: Tkinter / ttk
- **CLI**: Argparse

## Модель данных
Схема базы данных спроектирована с учетом каскадных удалений и ограничений целостности:

**IngredientCategory** — категории ингредиентов;
**RecipeCategory** — категории рецептов;
**Ingredient** — справочник ингредиентов (связан с категорией);
**Operation** — справочник кулинарных операций;
**Recipe** — основная сущность рецепта;
**RecipeIngredient** — связующая таблица состава рецепта (содержит количество и единицы измерения);
**RecipeStep** — шаги приготовления (связаны с операцией);
**recipe_step_ingredients** — таблица связи "многие-ко-многим" для привязки ингредиентов к конкретным шагам.

## Архитектура проекта
Код разделен на изолированные слои, что обеспечивает переиспользование бизнес-логики между CLI и GUI.

recipe_book/
├── models.py        # Декларативные модели SQLAlchemy
├── repositories.py  # Слой доступа к данным (запросы)
├── services.py      # Бизнес-логика, валидация входных данных
├── schemas.py       # DTO (Data Transfer Objects) на базе dataclass
├── db.py            # Настройка подключения, управление сессиями
├── seed.py          # Генератор тестовых данных
├── errors.py        # Иерархия исключений
├── cli.py           # Точка входа CLI
└── gui.py           # Точка входа GUI
